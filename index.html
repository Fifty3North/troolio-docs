How it fits

From command to read model.

The host controls ingress and authority. Troolio supplies framework contracts and optional provider surfaces for the path between command and projection.

01 · AdmitAuthenticate and authorize the current command in your host.
02 · PlanBuild a bounded causal event closure in memory.
03 · CommitPersist the selected batch and required handoffs atomically.
04 · ProjectUpdate read models after commit through projection workers.
