Release notes: 10.0.6

Troolio 10.0.6 publishes five packages for .NET 10 and Orleans 10: Core, Agents, SqlServer, KurrentDB, and KurrentDB.SqlServer. All five packages are available from NuGet.org; the four adapter packages are new public package IDs.

Adoption

Pin the same 10.0.6 version for all Troolio packages. Read packages for installation and deployment checklist for host responsibilities. The selected atomic path requires explicit authority, persistence capability, and recovery policy; ordinary actor use remains a separate route.

The public site documents current source contracts and provider boundaries. Consult the package metadata and your application's migration plan before upgrading an existing deployment.
