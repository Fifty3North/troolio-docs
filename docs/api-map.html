API map

This map points to the primary public contracts. Use the package XML documentation and source for overloads and exact semantics; many selected-route interfaces are intended for host/provider implementers.

Area Main types
Actor messaging IActor, Command<TActor>, Query<TActor,TResult>, Event, Metadata
Actor roles CqrsActor, EventSourcedActor, StatefulActor, ProjectionActor, OrchestrationActor
Storage IStore, IAtomicEventTransactionStore, IRouteFencedAtomicEventTransactionStore
Atomic transactions AtomicEventTransaction, AtomicEventTransactionRequest, AtomicEventTransactionReceipt, AtomicRouteFence
Selected ingress TrustedAtomicCommandIngressAdapter, TrustedAtomicCommandIdentityAuthority, route authority interfaces
Orchestration IEventOnlyOrchestrationStateStore, IEventOnlyOrchestrationDeliveryStore, DurableEventOnlySubscriberExecutor
Effects ExternalEffectIntent, IExternalEffectIntentStore, IIdempotentExternalEffectProvider, ExternalEffectDispatcher
Agents IAgentActor, IRunActor, AgentDefinition, RunSnapshot
SQL ISqlAtomicConnectionFactory, ISqlAtomicEventCodec, SqlAtomicTransactionEngine
KurrentDB KurrentSelectedActorStore, KurrentProjectionQueue and route admission interfaces
Combined adapter SqlKurrentBrokerOperationJournal, TrustedKurrentAdmissionGate, KurrentSqlProjectionConsumer
