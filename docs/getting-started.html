Get started

Install the framework in a .NET 10 host, then choose the provider and route your application will operate.

Requirements

  • .NET 10 SDK and a compatible runtime.
  • A Microsoft Orleans 10 host with package versions aligned across the application.
  • Acceptance of the license included with each Troolio package.

Install Core

Add the foundation package to your host project:

dotnet add YourHost.csproj package Troolio.Core --version 10.0.6

Add optional adapters as needed. For a SQL Server backed path:

dotnet add YourHost.csproj package Troolio.SqlServer --version 10.0.6

For KurrentDB, use Troolio.KurrentDB; add Troolio.KurrentDB.SqlServer only if the SQL coordination components are required. Agent contracts live in Troolio.Agents.

Pin all Troolio packages to the same version. Review the package map before choosing adapters.

Wire the host

  1. Define the current authenticated principal and command authorization at ingress.
  2. Choose a compatible event store and register the selected command route explicitly.
  3. Provide durable projection consumption, retry and recovery operations.
  4. Set provider idempotency and evidence retention windows for commands and external effects.

The library does not configure application authority or expose a production HTTP endpoint for you. Start with the command journey to understand the contracts before wiring a serving route.

Source material

Detailed package contracts are included in each NuGet package readme. The public documentation repository contains this site.
