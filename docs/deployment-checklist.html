Deployment checklist

Use this checklist when promoting a Troolio host that serves persistent actor traffic.

Build and compatibility

  • Pin all installed Troolio packages to 10.0.6 and use a compatible .NET 10 / Orleans 10 host.
  • Register the actor assemblies and the selected store/serializer explicitly.
  • Run package restore and integration tests against the same provider versions used in production.

Authority and storage

  • Authenticate and authorize ingress, actor targets, and selected routes.
  • Apply schema migrations and verify database transaction, locking, stream naming, and indexes.
  • Set the route epoch, reviewed deployment fingerprint, and serving silo/broker admission.
  • Define event retention, deletion fences, receipt lifetime, backups, and restoration drills.

Work after commit

  • Configure projection consumers, delivery workers, and retry scheduling.
  • Register external-effect providers with durable idempotency and pending-intent recovery.
  • Monitor queue lag, stale route rejects, append conflicts, operation receipts, and broker journals.
  • Test crashes before and after event append, receipt creation, projection claim, effect dispatch, and broker handoff.

An adapter package supplies code, not a production route by itself. The host owns the policies and operational controls. Start with host setup, then packages and recovery.
