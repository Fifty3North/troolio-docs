Glossary

Term Meaning
Actor path Stable identity of one actor, used in commands, ownership checks, and transaction participants.
Stream Ordered event history for one stream name and version sequence.
Event Immutable fact produced by a command and later replayed to reconstruct state.
Projection Consumer that turns committed events into a read-oriented view.
Handoff Durable marker or queue record connecting committed events to a projection consumer.
Operation ID Stable identifier for one command attempt and its retries.
Request identity Canonical SHA-256 digest of the original command identity and payload.
Participant Actor/stream, expected version, and events included in one closed atomic batch.
Route fence Route key, epoch, and deployment fingerprint checked during selected commit.
Completion receipt Durable evidence of what committed for an operation.
Event-only closure Bounded planning of causal subscriber events before a selected commit.
External-effect intent Durable record of a side effect to perform after event commit with a stable idempotency key.
Broker journal Durable evidence coordinating a KurrentDB write broker with SQL state.

Follow selected command route for the full request path or recovery for retry semantics.
