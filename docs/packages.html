Packages and compatibility

Troolio 10.0.6 targets .NET 10 and Orleans 10. Keep all installed Troolio packages on the same version. The five packages are available on NuGet.org:

Package Use
Troolio.Core Actor, event, store, transaction, orchestration, and projection contracts.
Troolio.Agents Agent definition and run actors.
Troolio.SqlServer SQL Server transaction, projection, route, and effect adapters.
Troolio.KurrentDB KurrentDB append, selected-route, queue, and recovery adapters.
Troolio.KurrentDB.SqlServer SQL coordination for KurrentDB broker, journal, admission, and projections.

Install Core first:

dotnet add package Troolio.Core --version 10.0.6

Add only integrations your application uses. The package references resolve their declared dependencies; the host must still register compatible services and own provider configuration. The combined KurrentDB/SQL package coordinates two stores using durable evidence; it does not create a distributed transaction.

Each package includes license/readme metadata. Review the bundled notices and provider requirements before redistribution or deployment. See getting started and host setup.
