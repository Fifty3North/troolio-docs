Packages

Five Troolio packages share version 10.0.6 and target .NET 10. Install Core first, then choose only the optional integrations your host uses.

PackagePurpose
Troolio.CoreEvent-sourced actor, command, transaction, and projection contracts. Includes the packaged Orleankka assemblies and upstream notices.
Troolio.AgentsAgent definition and run actor contracts and orchestration primitives.
Troolio.SqlServerOpt-in SQL Server transaction, read, projection, and orchestration adapters.
Troolio.KurrentDBKurrentDB stream, append, recovery verification, and projection integration.
Troolio.KurrentDB.SqlServerSQL Server support for KurrentDB journals, admission coordination, and projection helpers.

Version alignment

Use the same Troolio version across all installed Troolio packages. Align the Orleans dependency line across the host; these packages are built against Orleans 10.

Licensing and provider review

Each Troolio-owned package includes its license terms. Core also bundles Orleankka assemblies with separate upstream notices and license text. Review the provider readme and your deployment's schema, transaction, credentials, authorization, retention, and recovery design before activating an adapter.

The KurrentDB plus SQL Server package does not provide a distributed transaction spanning the two stores.
